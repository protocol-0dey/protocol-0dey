// process

From reference to release

Reference

A screenshot, a Figma frame or a mood board. I pin down the type scale, spacing and states first.

Build

Semantic markup, design tokens, components with loading, empty and error states.

Verify

Lint, types, unit and e2e tests, then a manual pass on desktop and phone, light and dark.

Ship

CI on every push, a mock API behind one module so a real backend plugs in cleanly.
