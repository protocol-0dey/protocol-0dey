# Concept landings

Landing pages built from a visual direction. Brands, prices and data are fictional.

| Page | Direction | Notes |
| --- | --- | --- |
| [WebTactics](webtactics_agency.html) | Dark digital agency, bento, 3D product | Animated portfolio filter (FLIP), mouse spotlight, mobile menu |
| [Aura XR](aura_xr.html) | Spatial-computing hardware launch | Floating 3D device, gradient type, glass cards, mobile menu |
| [Strato](strato_aviation.html) | Private aviation (RU) | Glass panels, booking modal |
| [Nexus](nexus_energy_landing.html) | Neon energy drink (RU) | Bento grid, order modal |
| [AquaGlow](premium_detailing_landing_page.html) | Car detailing studio (RU) | Price list, booking modal |

Shared work across the set: mobile navigation, modal forms with validation and a success state,
accessibility (dialog role, focus trap, Escape, `aria-invalid`), a `submitLead()` stub to swap for a real request,
and `overflow-x: clip` so decorative glows never cause sideways scroll on phones.

Open any file directly in a browser. Tailwind and fonts load from a CDN, so an internet connection is needed.
