# Reference sites

Five concept sites, each in a different visual language, written by hand in plain HTML, CSS and JavaScript
(no framework, no build step). Brands are fictional.

| Site | Direction | Interactive parts |
| --- | --- | --- |
| [Vector](vector/) | Dark AI dev-tool SaaS | Typing terminal with staged findings, cursor spotlight on bento cards, monthly / yearly pricing toggle, FAQ |
| [Nova One](nova/) | Glassmorphism product page | Colour picker that re-themes the whole page (keyboard radio group), 3D parallax product, ANC mode switcher |
| [Halo](halo/) | Bright fintech app | Animated gradient mesh, CSS phone mockup, 3D tilt card, compound-interest calculator |
| [Ember](ember/) | Warm e-commerce | Roast filters, cart drawer with focus trap and free-shipping progress, subscription builder, newsletter validation |
| [Monolith](monolith/) | Editorial architecture studio | Project index with a cursor-following preview, marquee, count-up stats |

Every page has a mobile layout and menu, visible focus states, `prefers-reduced-motion` support, and was checked
in a real browser at 1440 px and 390 px for horizontal overflow and script errors.
