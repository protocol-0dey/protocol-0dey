      // faq
      
Questions, answered.

      

        
Does Vector train on my code?
No. Your code is processed to produce a review and is never used to train models. Enterprise plans can run fully inside your VPC.

        
Which languages are supported?
TypeScript, JavaScript, Python, Go, Rust, Java, Kotlin, Ruby and PHP, plus config formats like Terraform and YAML.

        
Will it replace human reviewers?
It handles the mechanical part — bugs, edge cases, conventions — so humans can focus on design and intent.

        
How is a developer counted?
Anyone who opened a pull request reviewed by Vector in the billing period. Bots and read-only users are free.
